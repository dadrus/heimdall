Validating Admission Controller

A Kubernetes validating admission webhook checks heimdall RuleSet resources when they are submitted to the Kubernetes API server. This interface is available only for Kubernetes deployments using the Kubernetes rules provider.
On this page
  • Validate RuleSet

Validate RuleSet

POST /validate-ruleset
Validates a heimdall RuleSet submitted in a Kubernetes AdmissionReview request and returns the admission decision with validation feedback.

Parameters

  • timeout: string (query, optional)

    Maximum duration allowed for validation, such as 5s or 250ms. Accepted units are ns, us, ms, s, m, and h.

    Example: 5s

Request body required

A Kubernetes AdmissionReview request containing the RuleSet to validate.
